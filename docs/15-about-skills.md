# 关于我：头像与能力图谱

## 方向与范围

将用户指定的 ReactBits Pro Features 10 替换到「关于我」，保留其左侧介绍、右侧圆形连线与六节点结构。中心使用网站原有头像，周围以六项能力表达设计全栈、产品与工程实践。头像作为视觉中心，技能解释连接真实简历与项目。

组件从用户已配置的授权 registry 获取，通过现有 shadcn CLI 安装；实际导出为 `Features10`，本地适配仍保留 `use client`。背景、字体、浅蓝强调、内容宽度和按钮使用网站现有变量，没有引入全站 Tailwind reset。分支为当前目录的 `feat/about-skills-orbit`；首屏竖向收藏卡、探照灯作品墙、作品列表分类与经历内容保留。

## 简历信息如何抽象为标签

| 标签 | 显示的工具或方法 | 用户简历中的依据 |
| --- | --- | --- |
| 界面视觉 | Figma、Adobe、Procreate | 视觉传达学士、长期平面与手绘积累、UI 与图标设计 |
| 交互原型 | Figma、HTML / CSS | 抖音创作者中心 AI 助手的高保真原型、AI 对话与分镜编辑交互 |
| 工程实现 | HTML、Codex、Claude Code | 自由画布与图片生成 Agent、本地 TTS 配音应用的设计与开发 |
| AI 工作流 | ComfyUI、Agent、AIGC | AIxDesign 实验室课题、图像与视频生成、Agent 流程与可复现性评估 |
| 产品规划 | 需求分析、PRD、A/B 测试 | 简历产品技能、需求与架构梳理、原型实验和产品研发协作 |
| 用户研究 | 用户访谈、可用性测试 | 用户体验工程学习、创作者调研、真实产线工作流洞察 |

左侧以「设计全栈 / 产品思维 / 工程实践」整理跨度；六个图标表达能力类别。没有把工具熟练度画成百分比，也没有新增未经简历支持的专业头衔、开发语言或成果指标。

## 交互与回退

- 悬停、Tab 聚焦或手机点击节点，会选中对应能力，同时强调图标与连线，并更新固定区域的说明。按钮使用 `aria-pressed`，说明使用温和的状态播报。
- 入场保留节点渐显与连线绘制。图标仅轻微浮动 3px，点击区域与文字位置固定；中心外沿缓慢呼吸。离开视口或页面不可见时暂停循环。
- 开启减少动效后取消浮动、呼吸和入场位移，运行途中切换偏好立即生效。安装的 Motion 版本内置偏好 hook 只读取初始值，因此组件显式监听媒体查询变更。
- 头像和六项能力的内容源保留在 `index.html`。React 加载前、加载失败及关闭 JavaScript 时显示原生头像与能力列表，项目和经历链接继续有效。
- 原大照片与像素揭示入口被新图谱替换；移除对应运行代码、旧样式和已不再引用的五个生成文件。已安装的 PixelReveal 源文件保留在组件库中。

## 维护与验收

内容在 `index.html` 的 `#about-orbit-mount`，视觉与交互分别在 `about-skills.css`、`components/features-10.tsx`，接入入口为 `src/portfolio-enhancements.tsx`。修改组件后执行 `npm run typecheck`、`npm run build:interactions`，把生成资源和页面版本一同保存。

专属验收命令为 `python scripts/verify_about_skills.py`，覆盖七种视口连续三轮，共 21 组通过，检查六节点触屏/悬停、键盘、连线、头像加载、重叠、溢出、实时减少动效、离屏暂停、项目/经历链接及无 JS / 脚本失败回退。类型检查与交互资源构建通过。`scripts/verify_reactbits.py` 同步新头像入口后，桌面/手机与正常/减少动效连续三轮通过，共 12 组；`scripts/verify_portfolio.py` 的整站六种尺寸、四页资源与案例阅读器回归通过。另行检查关于我浅色主题。

按 Oil UI 存量润色流程完成一轮独立视觉评审，不打分。按反馈将六项说明与简历中的具体项目相连，保持专业名词完整换行，详情工具行由 11px 提至 12px，操作提示缩短为「选择能力，查看实践」。评审提出核对 Procreate；用户原始简历技能行明确列有「Procreate（手绘）」，因此保留。删除原「STAY CURIOUS」装饰文案及窄屏过小的英文副标题，保留头像、姓名和能力主线。

本轮证据位于 Git 忽略的 `.local/about-orbit/`：`before-*` 是原状，`viewport-copy-*` / `viewport-map-*` 为正常页面视口，`overview-*` 为隐藏固定导航后的区块辅助图，`motion-final/` 为节点操作录屏，`report.json` 为专属交互报告。测试环境为本机 Edge，未声称完成 Safari / iOS 真机验收。
