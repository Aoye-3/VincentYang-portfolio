# 作品宇宙与底部作品墙

## 目标与布局

用户指定使用 ReactBits Infinite Gallery 展示五个现有作品，并把探照灯照片墙移至页面底部。设计原则是先保证网页正常浏览，再由用户主动进入三维探索。

桌面左侧画廊、右侧介绍与作品入口；手机依次展示介绍、画廊及控制、五个作品入口。画廊采用 4:3 窗口，高度上限为视口的 60%，短屏按高度收缩，上下保留正常滚动区域。没有全屏滚动锁定或 body overflow 切换。

探照灯原区块整体移至联系区之后、版权栏之前，保留 `#honors-wall`、素材顺序、显影、漂移、暂停与触屏操作。顶部与底部章节目录增加「作品宇宙」，把「作品墙」放在最后，与实际顺序一致。首屏翻转收藏卡、作品筛选、关于我与经历内容保留。

## 五个独立作品与新增规则

当前独立作品数量为 **5**：AI 灵感助手、PMAgent-Canvas、DubbingRoom、江天黄鹤、Vivo 创意广告。无限空间会重复这些封面，空间中的实例数量不等于独立作品数量。

`index.html` 的 `#work-universe-mount` 与 `src/portfolio-enhancements.tsx` 均有中文数量注释。新增时：

1. 在挂载点添加一个 `data-universe-project` 原生封面链接，提供真实图片、作品地址和固有宽高。
2. 同步右侧 `.universe-index` 的作品入口。
3. 更新数量注释与介绍中的数量文案；画廊角标从实际数组长度计算。
4. 执行类型检查、交互资源构建和画廊验收。

封面按固有比例用于三维平面，没有把宽图拉伸成竖卡。DubbingRoom 原 SVG 仅有 viewBox，WebGL 上传时会出现黑色纹理；补齐 1200×675 的固有尺寸，矢量图形内容不变。接近相机的平面先淡出，避免未聚焦时单张封面遮满画廊。

## 交互状态

| 状态 | 画面 | 输入与退出 |
| --- | --- | --- |
| 默认预览 | 匀速向前漫游 | 没有画廊滚轮、拖动和触摸监听；滚轮、手指滑动仍滚动网页 |
| 探索中 | 手动拖动、滚轮穿行或双指缩放；点击封面可聚焦 | 点击「开始探索」进入；按钮变为「退出探索」，桌面支持 Esc；画廊外仍可滚动网页 |
| 暂停 / 减少动效 | 保留当前画面 | 可暂停漫游；减少动效取消自动漫游，仍可主动探索 |
| 离屏 / 页面不可见 | 停止持续渲染 | 自动退出探索，回到可自动预览的状态；返回视口后按用户暂停与动效偏好恢复 |
| 3D 加载失败 | 原生作品封面与作品入口 | 可继续打开作品，不依赖 WebGL |

滚轮和触摸监听只绑定到画廊 canvas，只有探索状态才安装。Ctrl / Meta + 滚轮保留浏览器缩放。鼠标坐标按画廊自身位置换算，画廊外的移动不驱动视差。手机使用「单指拖动 · 双指缩放 · 下方退出」说明，桌面使用滚轮与 Esc 说明。

## 实现与运行资源

通过用户提供的授权 registry 和现有 shadcn CLI 安装 `infinite-gallery-tw`；实际导出为默认 `InfiniteGallery`。使用现有 React、R3F、Three 与 Motion 依赖，没有新增 npm 包。

`src/portfolio-enhancements.tsx` 在接近区块时动态导入 `src/work-universe.tsx`，读取 HTML 中的封面数据。适配后的库组件增加 `interactive`、`paused` 与 `onReady`；自动速度按实际帧间时间计算，重复纹理请求合并，减少动效与离屏时使用按需渲染。原生内容在动态模块加载前或失败时继续有效。

构建使用 `npm run typecheck`、`npm run build:interactions`。主入口、共享 chunk、三维模块及许可文件位于 `assets/generated/interactions/`，需要随静态站一起保留。

## 视觉与交互验收

按 Oil UI 存量润色完成一轮独立截图评审，不打分。保留受控窗口、浅蓝选中态、常显作品入口和底部开放照片墙。按反馈区分手机操作说明、压缩引导文案，将雾化起点由 65 调至 90，让近景封面更清楚，同时保留远景层次。

- `scripts/verify_infinite_gallery.py`：七种视口连续三轮，共 21 组；验证未激活时滚网页、激活后仅局部滚轮、画廊外滚动、Esc、实时减少动效、暂停与真实画面变化、离屏退出及底部位置。另测无 JS 与 3D 脚本加载失败的原生入口。
- 额外使用浏览器真实触摸事件连续三轮，验证默认手指滑动滚网页、探索中仅操作画廊、点击退出；记录在 `touch-report.json`。
- `scripts/verify_portfolio.py`：四页资源与锚点、六种首页尺寸、探照灯显影与无缝循环、筛选和详情阅读器回归通过。
- `scripts/verify_page_progress.py`：24 组页面/视口检查通过，包含新增目录顺序、焦点、返回和复制状态。

证据在 Git 忽略的 `.local/infinite-gallery/`：`preview-*`、`exploring-*`、`wall-bottom-*`、`report.json`、`touch-report.json` 与浏览录屏。验证针对本机 Edge，未声称完成真实 Safari / iOS 验收。
