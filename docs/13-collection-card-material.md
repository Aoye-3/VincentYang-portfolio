# 收藏卡正反面设计

## 方向与范围

针对用户指出的单卡质感、尤其背面过于空泛的问题，把正反面统一成深色压纹收藏卡。保留网站现有黑紫背景、WY 品牌和项目强调色；真实项目图仍是正面的视觉主角。

- 正面：细化深灰蓝表面与边缘受光，封面采用完整等比展示和细边收口；提高类别文字尺寸，箭头收进小型轮廓标记。
- 背面：移除原来大号、低对比的 WY 水印；改用小型品牌印记、环绕细线刻纹、轻颗粒和内侧细线。上方标识作品集，下方清楚列出项目类别、名称及序号。
- 项目信息仍从原有 HTML 列表读取，背面类别也同步自正面，不另建一份内容数据。

刻纹与颗粒均为项目内静态 SVG，不依赖新增组件、着色器或动画循环。内框、表面明暗和颗粒都属于卡面，未给三维祖先增加滤镜、遮罩或透明度，因此保留正反面空间关系。

## 保留的行为

连续向下翻转、8 秒单卡节拍、悬停暂停与倾斜、键盘切换和案例入口均保留。手机、减少动效和无 JS 的展示路径继续可用。没有改动探照灯墙或页面其他组件。

## 验证与证据

四种宽度（320、1024、1440、1920）连续三轮检查，核对五张卡片的名称、类别、装饰素材加载及横向溢出，共 12 组通过。首屏专属脚本另检查六种视口、键盘、悬停、减少动效、无 JS 和两轮真实播放。

旧的悬停检查比较全部内联样式，会把尚在收敛的鼠标倾斜误判为播放未暂停；本轮改为检查自动行进的垂直位移保持不变，同时保留独立的悬停倾斜检查。

本轮证据在 `.local/card-material-20261020/`：`before-front.png` / `before-back.png`、`after-front-2x.png` / `after-back-2x.png`、默认翻转列截图、`material-checks.json` 和 `card-motion.webm`。正反面近景为浏览器临时固定到正视角的检查图；列截图与录屏使用实际交互。独立视觉评审仅针对本组件，不重评整站。

一轮独立视觉评审认为没有必须返工的问题；根据两项精修意见，减少刻纹线数、拉开线距，并降低 WY 字标及圆盘高光，使实际尺寸下的凹刻层次更清楚，印记更融入卡面。未发现需要删除的说明文字。六种视口及两轮真实播放验收通过。
