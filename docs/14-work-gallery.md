# 精选作品列表

## 目标与范围

用户指出作品区的跟随鼠标副标和大叠卡质感不足，希望参考 ReactBits 的列表展示，并保留「全部作品 / UI-UX设计 / AIGC媒体类」分类。目标是让真实作品封面和名称常显，方便比较并进入详情。

本轮在当前目录的 `feat/portfolio-work-gallery` 分支修改精选作品区。首屏竖向翻转卡片、探照灯照片墙及其交互保留；远端 main 仍为改版前存档，没有推送本轮修改。

## 组件选择

从用户指定的 ReactBits registry 读取实际组件源码，对比了三种展示：

| 组件 | 结构 | 判断 |
| --- | --- | --- |
| Showcase5 | 分类与自动滚动图片带 | 持续移动，不便同时比较作品 |
| Showcase7 | 原生案例链接、列表索引与预览 | 采用列表骨架，改为每行常显封面 |
| Showcase8 | 横向滚动卡片 | 部分项目位于屏幕外，增加浏览步骤 |

通过已安装的 shadcn CLI 导入 Showcase7 后，使用现有 React 交互入口接入；保留 `use client`、Motion 和 Lucide 图标，替换示例内容与样式。封面、字体、黑底和浅蓝强调色均沿用网站已有资源。组件没有新增鼠标跟随层或自动轮播。

## 列表与分类

每行包含封面、分类、作品名、一句介绍和固定「查看作品」入口，UI-UX 项目另有补充能力标签。整个条目是原生链接，支持 Tab 与 Enter；图片按原比例完整展示。桌面采用横向列表，手机先显示封面，再显示文字与入口；分隔线代替厚重的外框。

| 分类 | 作品 | 数量 |
| --- | --- | --- |
| 全部作品 | 以下全部项目 | 5 |
| UI-UX设计 | AI 灵感助手、PMAgent-Canvas | 2 |
| AIGC媒体类 | DubbingRoom、江天黄鹤、Vivo 创意广告 | 3 |

DubbingRoom 在媒体类中标为「AI 音频工具」。全部项目与封面均已存在于首页收藏卡中，没有添加虚构项目。分类继续使用 `main.js` 的原生筛选，数量改为从实际可见条目计算。

删除精选区的 `case-cursor`、`work-stack.css` 与 `work-stack.js`，相应旧样式和叠卡测试同步移除。首屏的收藏卡代码不受此调整影响。

## 加载与动效

`index.html` 保留完整列表，React 从该内容提取项目数据，避免两份独立内容源。加载前、组件加载失败以及关闭 JavaScript 时均可打开作品。React 接入时同步应用已经选中的原生分类，防止慢网下恢复到全部作品。

悬停或键盘聚焦仅让箭头位移 2px，时长 0.2 秒；筛选反馈为 0.24 秒的透明度变化，结果立即生效。快速连续切换先完成上一段反馈，避免内容停在半透明状态。减少动效模式取消这些位移和过渡。

## 视觉复核

按 Oil UI 存量润色标准进行一轮独立截图评审，不打分。保留常显真实封面、统一比例、开放黑色画布、细分隔线和分类下划线。按反馈将手机条目行间距由 20px 收为 12px、上下留白由 26px 收为 24px；删除音频与影像项目中重复介绍的标签，AI 灵感助手移除与分类重复的「交互设计」标签。入口提高到正文对比度，并在悬停或键盘聚焦时与标题同时显示浅蓝，增强同一行的关联。评审未发现需要返工的视觉阻断。

- `npm run typecheck`、`npm run build:interactions`：类型与预打包资源构建。
- `python scripts/verify_work_gallery.py`：320、390、768、1024、1440、1920px 和 1440×600 短屏，共七种视口连续三轮通过；分类数量、无重叠、无横向溢出、封面比例、减少动效与页面错误检查通过。额外验证慢加载时保留分类、键盘进入案例、无 JS 和组件加载失败时的原生入口。
- `python scripts/verify_portfolio.py`：四页链接、44 张板面、六种首页视口、照片墙、首屏暂停、主题和阅读器均通过。

- `python scripts/verify_reactbits.py`：现有创作预览和像素揭示在桌面/手机、正常/减少动效下连续三轮通过，共 12 组。
