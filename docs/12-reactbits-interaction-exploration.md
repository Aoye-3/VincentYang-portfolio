# ReactBits 接入与交互探索

## 配置和安装

本轮在原网站目录的 `feat/reactbits-interaction-exploration` 分支工作，远端 main 未改。当前页面仍可由静态 HTTP 服务直接运行，不要求迁移到 Next.js 或 Vite。

已安装官方 `shadcn` CLI。当前项目没有 `components.json`；CLI 初始化实际返回“不支持的框架”，因此按官方手动配置方式补齐 `components.json`、路径别名、Tailwind 源文件和 `cn()`。注册表地址完全使用用户提供的 `proxy.collectui.pro` Starter / Pro 地址。凭据仅保存在 `.env.local`，已验证被 Git 忽略，`.env.example` 不含真实值。

远程 `add` 遇到 Node 的连接超时 / `terminated`，而同一授权接口的 Python 请求返回正常 JSON。安装回退为：从该接口读取原始 registry 清单，再交给同一个官方 CLI 的本地清单模式安装；没有使用其他来源的组件源码。测试 `globe-tw` 完成安装后已删除，然后安装 `hover-preview-css` 和 `pixel-reveal-css`。

ReactBits 专属知识包已安装到工作区 `.agents/skills/react-bits-pro/SKILL.md`，组件选择和适配参考其真实源码及“已有网站优先”规则。Skill 中的上游 URL 与密钥前缀说明不覆盖本次用户提供的代理配置。

工作区 `.codex/config.toml` 中配置了官方 MCP，名称为 `shadcn`，以当前项目已安装的 CLI 启动，工作目录、临时文件和缓存均在 F 盘。初始化握手和 `tools/list` 已通过，返回七项工具。重启 Agent 会话后加载此配置；它是官方 shadcn MCP，没有额外安装所谓 ReactBits 专属 MCP。

## 本轮走查

北极星：让真实作品在一个连续的展陈空间里被发现、被理解，动效负责带路和回应操作。

按 Oil UI 的存量界面模式进行了一轮独立截图走查，不打分。证据含 1440×900 与 390×844 的全页和分区截图；静态阅读截图开启减少动效，正常三维首屏沿用上一轮证据。

| 发现 | 本轮调整 |
| --- | --- |
| 作品墙静止状态过暗，减少动效时尤甚 | 放松最外层暗幕；减少动效底图 opacity 从 .16 调到 .55，保留原有探照灯、图片顺序、比例、漂移与暂停 |
| 首屏点阵与后续纯黑空间交接生硬 | 墙面顶部用同色静态点阵逐渐收暗，不叠加另一套全屏背景 |
| 手机案例文字较长，真实项目图出现较晚 | 窄屏将现有项目图放到卡片首行，项目文案和案例入口紧随其后 |
| 更多创作的符号比真实作品醒目 | 改为带真实缩略图的作品索引；鼠标或键盘可查看更大图片 |

删去了首屏角落的重复英文口号和两个案例图的装饰英文标题，案例入口统一使用中文。保留署名、项目名称、判断能力所需的描述和实际导航标签。

## 选择与适配

### 图片预览：hover-preview

用于更多创作索引。默认状态就能看见图片与名称，桌面预览出现在右侧空区，避免盖住正在阅读的链接；跟随移动只保留小幅度旋转和偏移。

对安装源码作了适配：触发器改为真实链接，补齐键盘焦点、Escape、滚动/窗口变化时关闭、计时器清理和减少动效。手机与减少动效模式直接使用真实缩略图，不依赖悬停。图片以 contain 显示，项目画面不裁切；原案例深链接继续可用。

### 一次图片揭示：pixel-reveal

用于个人介绍图片，0.9 秒的点阵揭示呼应首页材料。组件只在图片进入视口时动态加载，正常完成后卸载 WebGL 层；保留原生图片在下面。减少动效不创建图层，加载失败则保留原图。没有再添加全站鼠标尾迹、另一套三维相册或额外背景着色器。

### 操作之间的连续性

分类切换保留即时筛选结果，只对卡片内部内容加 240ms 的 Motion 透明度反馈，避免覆盖原有叠卡 transform。底部目录使用同一块移动的选中框，手机展开后同样定位到当前章节。减少动效时状态直接到位。

地球只用于安装验证：目前没有地点或全球协作内容支撑它，故未放进作品集。首屏悬浮卡片、探照灯墙和原有滚动叠卡继续承担主要展示，不再装入另一套同职责的 Pro 页面块。

## 开发和验证

```powershell
npm run typecheck
npm run build:interactions
python scripts/verify_reactbits.py
```

入口为 `src/portfolio-enhancements.tsx`，安装并适配的组件在 `components/`。构建输出在 `assets/generated/interactions/`，包含现有静态站可直接使用的 JS/CSS，以及按需加载的图片揭示文件。Tailwind 源样式没有导入全站，避免 reset 影响现有页面。

新交互检查覆盖桌面 / 手机、正常 / 减少动效，连续三轮，共 12 组；另测无 JS 和组件脚本加载失败时的原生链接。原有整站、叠卡与四页目录脚本一并复验。截图与报告在 `.local/reactbits-exploration/`，MCP 握手报告在 `.local/reactbits-setup/mcp-check.json`。检查基于本机 Edge，尚未做真实 Safari / iOS 验收。

TypeScript 检查和交互资源编译通过。安装输出报告 9 项高危依赖告警，`npm audit --omit=dev` 的运行依赖审计为 0 项；工具链告警尚未处理，本轮未执行可能改变 CLI 行为的强制升级。

第三方 ReactBits 源码和 npm 依赖遵循其各自许可，不因网站原模板采用 MIT 而重新授权。本轮没有将新版或授权组件推送到公开远端。
