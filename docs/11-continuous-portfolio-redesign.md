## 设计方向

让真实作品成为连续浏览的主线：从首屏收藏卡进入作品墙，再进入可阅读的案例与个人经历。保留紫色点阵、黑色展陈空间和浅蓝操作色，通过一致的内容宽度、中文导航、标题层级和区块留白连接各部分。

主要任务是浏览代表作、判断设计与产品实践能力，并找到联系渠道。主操作为“探索我的作品”，落到精选案例；作品墙保留自由探索入口。没有新增虚构项目、指标或联系信息。

## 实际调整

- **竖向悬浮卡片**：保留连续翻转、悬停倾斜和暂停、键盘选项及案例入口。增加展示区高度，调整外围卡片间距，并在卡片接近展示区边界前逐渐淡出，消除硬截断。三维祖先不使用 opacity、filter 或 mask，避免正反面被压平。收暗侧立卡片边缘。窄屏继续使用原有静态/手动浏览模式。
- **探照灯照片墙**：保留倾斜排列、UX / UX / 获奖记录的顺序、原图比例、漂移、暂停和触屏显影。调亮未探索时的底图，降低标题尺度，缩短区块，使它衔接首屏和案例。修复 IntersectionObserver 同批多条记录只检查第一条导致偶发不初始化的问题：预载检查任一进入记录，播放状态使用最新记录。
- **精选案例与个人经历**：统一标题与正文尺寸，减少叠卡尾部空白。经历仍使用原生 details，展开后随页面自然延长，取消内部滚动框。
- **导航**：顶部与底部使用相同标签及落点。桌面保持固定目录，手机收为“当前章节 + 联系/返回”条，点击展开两列目录；支持 Escape、焦点返回、点选关闭和点击外部关闭。展开层使用不透明背景。
- **更多创作和联系区**：创作卡片使用已有真实图片，鼠标悬停和键盘焦点都能预览，触屏直接显示。联系区以静态点阵呼应首屏，移除前方重复分隔和过大空白。未配置邮箱时，“联系”跳转现有联系渠道。

原有分类筛选、案例地址、44 张板面、阅读器、主题切换、减少动效和无 JavaScript 内容入口保留。
