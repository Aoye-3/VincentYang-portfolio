## 当前实现

`hero-atmosphere.css` 与 `hero-atmosphere.js` 提供首页独立装饰层：稀疏光尘、斜向冰蓝柔光，下缘过渡淡紫、浅桃色与暖白。左侧保持暗色，保护介绍文字。其定位不参与布局，且不接收鼠标事件；没有在 3D 卡片祖先上添加滤镜或遮罩。原卡片的黑色边缘伪元素背景清空，避免遮住新增柔光；正反面与翻转逻辑保持原样。

粒子最多 130 个、手机最多 40 个；画布最大约 180 万像素，DPR 最大 1.5，绘制不超过 30 次/秒。离屏、后台、减少动态效果时停止 RAF；减少动态效果保留静态粒子，无 JS 保留 CSS 柔光。

全站颜色集中在 `custom.css`：`--accent`、`--action-bg`、`--action-ink`、`--action-hover`、`--brand-gradient`、`--context-*`。主按钮、筛选选中项、底栏操作共享冰蓝填充；底栏轨道为深蓝灰，当前项冰蓝描边。浅色模式单独调整底栏文字与背景对比度，首页仍保持暗色舞台。项目封面的原始颜色与每个作品的小面积类别色保留。

当前是本地程序背景，尚未接入生成的视频。参考文件的整站 React 复刻说明仅作背景视觉资料；本站未引入其框架、商标、业务文字或远程视频资源。

验收：`python scripts/verify_atmosphere.py` 覆盖 360–1920px 的动画、颜色一致、指针穿透、原 3D 深度、减少动效、离屏及模拟后台条件；无 JS 链接有效。报告与截图在 `.local/atmosphere/`。真实后台设备调度和视频效果需在接入素材后重新确认。

## 视频生成提示词

为个人设计师作品集网站生成抽象背景视频，只生成背景，没有任何文字或界面。整体为炭黑色空间，右上角带极淡的墨绿色暗光。一道柔和的斜向光带从左下方延伸至右上方，主要亮部位于画面右侧和右下角。光带上缘是清透的冰蓝色与柔白高光，下方依次晕染淡薰衣草紫、浅桃粉和奶油白，色彩细腻融合，具有柔和的体积光与电影胶片质感。左侧约 55% 的区域保持深暗、低对比、低细节，为白色介绍文字留出空间。右侧光晕缓慢流动，少量细小光尘以极慢速度漂移，微弱闪烁。固定镜头，没有推进、旋转或切镜，没有突然变亮或明显形变。运动宁静、克制，适合长时间循环观看。首尾构图、光带位置和亮度一致，尽可能无缝循环。16:9，1920×1080，8–10 秒，24 或 30fps，无音轨。

负面提示：文字、字母、Logo、网页、按钮、卡片、人物、星球、飞船、山体、密集星空、粒子连线、赛博朋克、强烈霓虹、高饱和虹彩、频闪、爆炸、镜头移动、纯白大面积过曝。

生成后使用用户提供的 MP4 接入。循环衔接需实际检查；生成提示不能保证首尾完全无缝。继续保留静态背景作为加载失败与减少动态效果时的后备。
