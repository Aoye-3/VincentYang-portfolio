# 页面进度菜单

更新：2026-09-21。分支 `feat/page-progress-menu`，纯静态 HTML/CSS/JS。

## 结构与内容源

菜单位于原顶栏下方，顶部固定、水平居中。左侧深灰区域显示本页章节，黄色描边标识当前位置，细线显示当前段落的滚动进度；右侧黄色区域用于联系或返回。手机左侧可横向滑动，黄色操作始终可见。

```text
site-header                     原品牌、导航与主题操作
page-progress                   固定进度菜单
├─ page-progress-mark           W. / 返回首页（手机隐藏）
├─ page-progress-links          灰色章节轨道
└─ page-progress-action         Contact me / 返回上一页
```

首页：Home → `#home`；荣誉墙 → `#honors-wall`（原斜向图片墙）；精选作品 → `#work-title`；更多作品 → `#interests`（自动展开兴趣区）；个人简历 → `#about`（当前个人介绍与经历，非下载附件）；联系我 → `#contact`。菜单顺序按需求展示，滚动高亮按目标在文档中的实际位置计算。

详情页把原 `.case-toc` 移到顶栏下方，增加 `.page-progress` 外观与返回按钮。原 `.case-toc-links` 内的章节链接就是内容源，避免维护两份目录；原章节滚动高亮仍由 `main.js` 管理。图片、案例、阅读器及稳定锚点保留。

## 文件与参数

- `page-progress.css`：独立外观与响应式。桌面 top 90px、内容避让 170px；手机 top 76px、避让 146px。同步调整原项目筛选栏 sticky top，叠卡组件会自动重新测量。
- `page-progress.js`：首页当前块、段落进度、灰色轨道横向跟随、复制反馈与返回地址。
- `index.html` / 三个详情 HTML：语义化链接与菜单结构，无 JS 仍可跳转。
- `scripts/verify_page_progress.py`：24 组页面/视口检查，加复制成功/拒绝、章节跳转后的返回与无 JS 导航。

图片墙设置 `overflow-anchor: none`：其懒加载的斜向图片轨道不能参与浏览器滚动锚定，否则首次点击目录后会被浏览器拉回。无需拦截原生锚点点击或接管页面滚动。

首屏仅增加顶部避让空间，未更改收藏卡数据、外壳或动效。浅色模式下菜单仍保留参考图的灰色与黄色。减少动态效果沿用网站设置，导航不启用额外循环动效。

## 邮箱与返回

首页公开邮箱配置在黄色按钮的 `data-copy-email` 中。必须填写用户确认的真实地址；目前该值等待用户提供，不从其他个人材料推断。复制成功后显示「邮箱已复制」，权限拒绝时显示可选中的邮箱供手动复制。验收脚本在缺少真实邮箱时仅在浏览器内使用 `fixture@example.com` 测试复制机制，测试地址不会写入网站。

详情黄色按钮默认返回 `../#work-title`；若有同源、不同页面的 referrer，则返回该页面。直接打开详情也有稳定的返回入口。不直接调用 `history.back()`，因为阅读期间的章节锚点也会进入浏览历史，可能导致按钮只返回上一章节。

## 验收与维护

启动本地 5501 服务器，运行：

```powershell
python scripts/verify_page_progress.py
python scripts/verify_work_stack.py
python scripts/verify_portfolio.py
```

截图和报告分别在 `.local/page-progress/`、`.local/work-stack/`、`.local/acceptance/`。浏览器临时文件留在本仓库。修改两个组件文件后更新四页中的 `?v=` 内容哈希，以免缓存旧版本。新增章节时修改本页 HTML 的目录链接并提供相应 id，不需另建菜单数据数组。

本轮验收通过：4 页 × 6 种宽度（360、390、768、1024、1440、1920）的固定位置、锚点、当前块和横向溢出；复制成功与拒绝回退（测试地址）、多次章节跳转后的返回、无 JS 详情导航。全站菜单、图片墙、兴趣展开、主题及案例阅读器回归通过。叠卡在 1440×900、1920×1080、768×1024 正常，1024×768 因新增菜单压缩可用高度而按既有规则恢复普通列表。
